This result comes from a finite-element heat-transfer analysis of a race car brake disk executed on Raspberry Pi Cluster v2.

The cluster ran the parallel workload using the OpenMPI library, demonstrating that the compact portable cluster could support meaningful engineering-compute experiments beyond simple test jobs.

After the simulation completed, the thermal result was visualized in ParaView for post-processing and presentation.
