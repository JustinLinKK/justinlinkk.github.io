# Second High-Performance PC Build

This is my second high-performance PC build, designed to maximize my production ability across hardware and software projects. The goal is to have enough local compute, memory, GPU throughput, and thermal headroom to move quickly between AI experiments, hardware development workflows, simulation, compilation, and daily engineering work.

## Hardware Summary

| Component | Details |
| --- | --- |
| CPU | AMD Ryzen 9 9950X3D |
| Memory | G.Skill 96 GB dual-channel DDR5-6000 CL28 |
| GPU | NVIDIA GeForce RTX 5090 |
| Cooling | Custom water-cooling setup |

This build gives me a stronger workstation base for GPU-heavy software work, RTL and FPGA development, local model experiments, CAD and simulation tasks, and multi-tool engineering workflows.
