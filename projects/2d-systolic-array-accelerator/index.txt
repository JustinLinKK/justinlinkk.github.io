9:Td94,<h1>Project Title: 2-D Systolic Array Accelerator (ECE284)</h1>
<h2>Project Overview</h2>
<p>This project implements and analyzes a 2-D systolic array accelerator for deep neural network inference. It begins with a weight-stationary baseline and evolves into a reconfigurable architecture with SIMD support, output-stationary mode, and alpha-stage optimizations for accuracy, sparsity, and power efficiency.</p>
<h2>Objectives</h2>
<ul>
<li><strong>High-Throughput Matrix Multiply:</strong> Use a grid of processing elements (PEs) to maximize data reuse and minimize memory traffic.</li>
<li><strong>Reconfigurable Dataflow:</strong> Support both Weight Stationary (WS) and Output Stationary (OS) modes for different layer shapes.</li>
<li><strong>Low-Precision Acceleration:</strong> Enable INT4 baseline and INT2 SIMD packing to increase throughput.</li>
<li><strong>Power and Sparsity Optimizations:</strong> Incorporate skip logic and clock gating for sparse workloads.</li>
</ul>
<h2>Architecture Highlights</h2>
<ul>
<li><strong>2-D PE Array:</strong> Systolic data movement across rows and columns for regular, high-bandwidth compute.</li>
<li><strong>WS Mode:</strong> Weights stay resident in PEs while activations stream through the array.</li>
<li><strong>OS Mode:</strong> Partial sums accumulate within PEs to reduce off-chip traffic.</li>
<li><strong>SIMD INT2:</strong> Two INT2 operations packed into a single INT4 datapath for doubled effective throughput.</li>
</ul>
<h2>Project Structure</h2>
<ol>
<li>
<p><strong>Part 1: Vanilla WS Array</strong></p>
<ul>
<li>Baseline weight-stationary implementation.</li>
<li>Validated with a quantized VGG16 layer on CIFAR-10.</li>
</ul>
</li>
<li>
<p><strong>Part 2: SIMD Support</strong></p>
<ul>
<li>Adds INT2 support using SIMD packing within the MAC datapath.</li>
</ul>
</li>
<li>
<p><strong>Part 3: Reconfigurable Array</strong></p>
<ul>
<li>Adds OS mode for flexible dataflow selection.</li>
</ul>
</li>
<li>
<p><strong>Part 4: Poster</strong></p>
<ul>
<li>Presentation material summarizing the architecture and results.</li>
</ul>
</li>
<li>
<p><strong>Part 5: Alpha Enhancements</strong></p>
<ul>
<li><strong>Optimized Training:</strong> Adam optimizer, cosine scheduler, and label smoothing to recover quantized accuracy.</li>
<li><strong>Coarse-to-Fine Pruning:</strong> Mixed pruning to improve sparsity with minimal accuracy loss.</li>
<li><strong>Gating and Power Saving:</strong> Zero-skipping and clock gating in OS mode.</li>
<li><strong>Multi-Tiling:</strong> Scalable multi-core tiling for larger workloads.</li>
</ul>
</li>
<li>
<p><strong>Reports</strong></p>
<ul>
<li>Final report and progress report documenting design decisions and results.</li>
</ul>
</li>
</ol>
<h2>Tooling</h2>
<ul>
<li><strong>Hardware Simulation:</strong> Verilog simulation with standard EDA tools.</li>
<li><strong>Software Modeling:</strong> Python, PyTorch, and Jupyter notebooks for training and analysis.</li>
<li><strong>GitHub:</strong> <a href="https://github.com/JustinLinKK/ece284-project">https://github.com/JustinLinKK/ece284-project</a></li>
</ul>
<h2>Outcomes</h2>
<ul>
<li>Demonstrated a functional 2-D systolic array with reconfigurable WS/OS dataflows.</li>
<li>Achieved higher throughput for low-precision workloads via SIMD packing.</li>
<li>Validated power-saving mechanisms for sparse operations.</li>
<li>Documented architectural tradeoffs and optimization results in reports and poster.</li>
</ul>
