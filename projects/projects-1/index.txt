9:T199c,<h1>Project Title: Raspberry Pi Cluster v1</h1>
<h2>Project Overview</h2>
<p>The Raspberry Pi Cluster v1 is a custom-built, seven-node computing cluster designed to explore distributed computing, parallel processing, and web hosting capabilities. This project integrates various Raspberry Pi models into a cohesive system, utilizing SLURM and Kubernetes for efficient resource management and task scheduling.</p>
<h2>Objectives</h2>
<ul>
<li><strong>Distributed Computing:</strong> Leverage SLURM and OpenMPI to enable parallel processing across multiple nodes, facilitating the execution of computational tasks that benefit from distributed architectures.</li>
<li><strong>Web Hosting:</strong> Deploy Kubernetes to manage containerized applications, specifically hosting the IEEE McMaster Student Branch website, ensuring scalability and reliability.</li>
<li><strong>Educational Exploration:</strong> Provide a hands-on platform for learning about cluster computing, network configuration, and system administration.</li>
</ul>
<h2>Hardware Components</h2>
<ul>
<li><strong>Master Node:</strong> 1 x Raspberry Pi 4 Model B with 4GB RAM.</li>
<li><strong>Compute Nodes:</strong> 6 x Raspberry Pi 3 Model B with 1GB RAM each.</li>
<li><strong>Networking:</strong> A managed Ethernet switch to facilitate high-speed communication between nodes.</li>
<li><strong>Power Supply:</strong> Centralized power distribution system ensuring consistent and reliable power to all nodes.</li>
<li><strong>Enclosure:</strong> Custom CAD-designed shells for housing the Raspberry Pi units, optimizing space and airflow.</li>
</ul>
<h2>Software Configuration</h2>
<ul>
<li><strong>Operating System:</strong> Each node runs a Linux-based OS optimized for ARM architecture.</li>
<li><strong>Cluster Management:</strong>
<ul>
<li><em>SLURM:</em> Implemented for job scheduling and workload management, enabling efficient distribution of computational tasks across the cluster.</li>
<li><em>OpenMPI:</em> Installed to support the development and execution of parallel applications using the Message Passing Interface (MPI) standard.</li>
</ul>
</li>
<li><strong>Container Orchestration:</strong>
<ul>
<li><em>Kubernetes:</em> Deployed to manage containerized applications, providing automated deployment, scaling, and operation of application containers.</li>
</ul>
</li>
<li><strong>Networking Services:</strong>
<ul>
<li><em>DHCP Server:</em> Configured on the master node to assign IP addresses to compute nodes, ensuring seamless network integration.</li>
</ul>
</li>
</ul>
<h2>Implementation Details</h2>
<ol>
<li>
<p><strong>Hardware Assembly:</strong></p>
<ul>
<li>Designed and 3D-printed custom enclosures for each Raspberry Pi to ensure secure mounting and adequate cooling.</li>
<li>Connected all nodes to a central managed Ethernet switch to facilitate efficient inter-node communication.</li>
<li>Established a centralized power supply system capable of delivering consistent power to all nodes, considering the specific power requirements of Raspberry Pi devices.</li>
</ul>
</li>
<li>
<p><strong>Operating System Installation:</strong></p>
<ul>
<li>Installed a lightweight Linux distribution on each Raspberry Pi, optimizing system performance and resource utilization.</li>
<li>Configured SSH access for remote management and streamlined administrative tasks.</li>
</ul>
</li>
<li>
<p><strong>Network Configuration:</strong></p>
<ul>
<li>Set up a DHCP server on the master node to dynamically assign IP addresses to each compute node, simplifying network management.</li>
<li>Ensured all nodes are on the same subnet to promote efficient communication and data transfer.</li>
</ul>
</li>
<li>
<p><strong>Cluster Software Deployment:</strong></p>
<ul>
<li>Installed and configured SLURM on all nodes to manage job scheduling and resource allocation effectively.</li>
<li>Deployed the OpenMPI library to support the development and execution of parallel applications across the cluster.</li>
</ul>
</li>
<li>
<p><strong>Container Orchestration Setup:</strong></p>
<ul>
<li>Installed Kubernetes on the cluster to orchestrate containerized applications, providing a robust platform for deploying and managing services.</li>
<li>Deployed the IEEE McMaster Student Branch website within the Kubernetes environment, ensuring high availability and scalability.</li>
</ul>
</li>
</ol>
<h2>Challenges and Resolutions</h2>
<ul>
<li><strong>Hardware Compatibility:</strong> Addressed differences between Raspberry Pi 4 and Raspberry Pi 3 models by ensuring uniform operating system configurations and compatible software versions across all nodes.</li>
<li><strong>Dependency Management:</strong> Resolved issues with missing packages and version conflicts by meticulously managing source code dependencies and utilizing virtual environments where necessary.</li>
<li><strong>Network Stability:</strong> Ensured reliable network performance by configuring quality of service (QoS) settings on the managed switch and monitoring network traffic to prevent bottlenecks.</li>
</ul>
<h2>Outcomes</h2>
<ul>
<li><strong>Enhanced Computational Capability:</strong> Successfully established a functional Raspberry Pi cluster capable of handling parallel processing tasks, thereby increasing computational efficiency.</li>
<li><strong>Reliable Web Hosting Platform:</strong> Deployed the IEEE McMaster Student Branch website on the cluster, demonstrating the system's capability to manage real-world web applications.</li>
<li><strong>Educational Advancement:</strong> Gained practical experience in cluster assembly, network configuration, and the deployment of distributed computing frameworks, contributing to a deeper understanding of scalable computing solutions.</li>
</ul>
<h2>Future Plans</h2>
<ul>
<li><strong>Performance Optimization:</strong> Analyze the cluster's performance metrics to identify and address potential bottlenecks, aiming to enhance processing speed and efficiency.</li>
<li><strong>Scalability Testing:</strong> Explore the feasibility of expanding the cluster by adding more nodes and evaluating the impact on performance and resource management.</li>
<li><strong>Diverse Workload Integration:</strong> Experiment with running a variety of workloads, including data analysis, machine learning tasks, and additional web services, to assess the cluster's versatility and robustness.</li>
</ul>
<p>This project serves as a foundational platform for ongoing exploration and development in the fields of distributed computing and system administration.</p>
