9:T18a8,<h1>Project Title: Cube_Mini</h1>
<h2>Project Overview</h2>
<p><strong>Cube_Mini</strong> is a compact self-balancing cube powered by two ESP32 microcontrollers and three brushless Permanent Magnet Synchronous Motors (PMSMs). Inspired by the CubeMini project on <a href="https://github.com/ZhaJiHu/Cubli_Mini">GitHub</a> , this system combines advanced sensor feedback, precise PID control, and real-time wireless communication to dynamically maintain balance in three dimensions. The frame is built with lightweight carbon fiber and reinforced with custom 3D-printed corners for structural integrity.</p>
<h2>Objectives</h2>
<ul>
<li><strong>Self-Balancing Control:</strong> Implement real-time PID feedback loops using inertial measurements to actively stabilize the cube in three axes.</li>
<li><strong>Modular Motor Control:</strong> Use distributed microcontroller architecture where each ESP32 manages motor control independently and communicates over WiFi.</li>
<li><strong>Wireless Parameter Tuning:</strong> Enable remote control and dynamic tuning of PID parameters through a custom WiFi TCP protocol for real-time system adjustment and calibration.</li>
<li><strong>Lightweight and Durable Design:</strong> Utilize carbon fiber and 3D-printed components to minimize weight while maximizing mechanical stability.</li>
</ul>
<h2>Hardware Components</h2>
<ul>
<li><strong>Microcontrollers:</strong>
<ul>
<li>1 x ESP32 (controls 1 PMSM, acts as WiFi host)</li>
<li>1 x ESP32 (controls 2 PMSMs, WiFi client)</li>
</ul>
</li>
<li><strong>Motors:</strong> 3 x Brushless Permanent Magnet Synchronous Motors (PMSMs)</li>
<li><strong>Sensors:</strong> 1 x MPU6050 6-DOF IMU (accelerometer + gyroscope)</li>
<li><strong>Structural Frame:</strong>
<ul>
<li>Carbon fiber rods for the main structural frame</li>
<li>Custom 3D-printed corners for motor mounting and frame joints</li>
</ul>
</li>
<li><strong>Power Supply:</strong> Li-Po battery pack and motor driver circuits designed for low-latency operation</li>
</ul>
<h2>Software Configuration</h2>
<ul>
<li><strong>Motor Control:</strong>
<ul>
<li>PID loops implemented for real-time control of motor torque based on tilt angle and angular velocity feedback</li>
<li>Sensor fusion from the MPU6050 for stable gravity vector estimation</li>
</ul>
</li>
<li><strong>Communication:</strong>
<ul>
<li>WiFi-based TCP socket communication between ESP32 nodes</li>
<li>Host ESP32 acts as control hub, accepting parameter updates via external interface</li>
</ul>
</li>
<li><strong>Sensor Integration:</strong>
<ul>
<li>Real-time data acquisition from the MPU6050</li>
<li>Sensor calibration and filtering for noise reduction and accurate orientation data</li>
</ul>
</li>
<li><strong>Parameter Tuning Interface:</strong>
<ul>
<li>Custom TCP protocol allows live PID gain tuning, data monitoring, and diagnostics over wireless connection</li>
</ul>
</li>
</ul>
<h2>Implementation Details</h2>
<ol>
<li>
<p><strong>Mechanical Design:</strong></p>
<ul>
<li>Designed a minimalistic cube using carbon fiber tubes for weight efficiency and structural strength</li>
<li>Modeled and printed 3D-printed motor mounts and corners to support each motor at the cube’s edges</li>
</ul>
</li>
<li>
<p><strong>Motor and Sensor Wiring:</strong></p>
<ul>
<li>Routed power and control signals through hollow carbon fiber tubes</li>
<li>Integrated MPU6050 securely at the geometric center of the cube for optimal inertia measurement</li>
</ul>
</li>
<li>
<p><strong>ESP32 Control Architecture:</strong></p>
<ul>
<li>Programmed one ESP32 to handle a single-axis control and host TCP server for PID parameter input</li>
<li>Second ESP32 handles two axes, receiving instructions from the host node and executing synchronized motor commands</li>
</ul>
</li>
<li>
<p><strong>Control System Development:</strong></p>
<ul>
<li>Tuned PID loops for each motor based on real-time sensor feedback</li>
<li>Developed filtering algorithms to mitigate gyro drift and sensor noise</li>
</ul>
</li>
<li>
<p><strong>Wireless Protocol Design:</strong></p>
<ul>
<li>Implemented a low-latency TCP interface using ESP-IDF framework for robust two-way communication</li>
<li>Created Python-based ground station interface to send PID parameters and monitor system response</li>
</ul>
</li>
</ol>
<h2>Challenges and Resolutions</h2>
<ul>
<li><strong>Sensor Drift and Noise:</strong> Applied Kalman and complementary filters to stabilize accelerometer and gyroscope outputs.</li>
<li><strong>Motor Sync Timing:</strong> Resolved timing jitter between ESP32s by implementing soft time-synchronization protocol over TCP.</li>
<li><strong>Wireless Latency:</strong> Optimized TCP packet size and reduced unnecessary message overhead to ensure fast PID loop updates.</li>
<li><strong>Frame Resonance:</strong> Addressed mechanical resonance by reinforcing joints and tuning PID values to reduce oscillatory behavior.</li>
</ul>
<h2>Outcomes</h2>
<ul>
<li><strong>Functional Self-Balancing Cube:</strong> Achieved dynamic equilibrium on all three axes using a distributed control system and feedback loops.</li>
<li><strong>Live PID Tuning:</strong> Enabled real-time parameter tuning via WiFi, drastically reducing iteration time during testing.</li>
<li><strong>Modular Hardware Design:</strong> Validated the modular architecture, allowing future replacement or scaling of motor/ESP components.</li>
<li><strong>Educational Value:</strong> Gained experience in closed-loop control systems, sensor integration, embedded communication, and system dynamics.</li>
</ul>
<h2>Future Plans</h2>
<ul>
<li><strong>Closed-Loop System Modeling:</strong> Integrate real-time telemetry and Bode plot visualization to enhance control system analysis.</li>
<li><strong>Mobile App Interface:</strong> Develop a user-friendly app for Bluetooth or WiFi tuning without a PC interface.</li>
<li><strong>Advanced Motion Behaviors:</strong> Implement trajectory planning and dynamic rebalancing for hopping, reorientation, and controlled falling.</li>
<li><strong>Sensor Redundancy:</strong> Add magnetometer or secondary IMU for improved spatial awareness and fail-safe control.</li>
</ul>
<p>This project showcases a high-performance, scalable platform for exploring embedded control systems and real-time dynamics in robotics.</p>
